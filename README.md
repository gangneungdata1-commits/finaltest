# 📅 일정비서관 — 공무원 일정 보고서 자동화

> 매주 반복되는 보고서 작성, 이제 일정비서관에게 맡기세요.

---

## 1. 만들게 된 동기 (Why)

공공기관에서는 매주/매월 반복적으로 "주간업무보고", "월간업무보고" 같은 보고서를 작성합니다.
하지만 실제 작업은 대부분 다음과 같이 비효율적으로 이루어집니다.

- 메신저, 메모, 메일로 흩어진 일정을 일일이 모아 정리
- 정해진 양식(HWPX)에 맞춰 번호·서식·문구를 수작업으로 맞춤
- 부서/담당자별로 다시 분류, 대내외 구분, 날짜 정렬 등 단순 반복 작업 반복

**일정비서관**은 이 반복 작업을 자동화하여, 담당자가 "내용 입력"에만 집중하고 보고서 형식 변환은 도구가 대신하도록 만든 도구입니다.

---

## 2. 핵심 기능 (What)

| 기능 | 설명 |
| --- | --- |
| 📝 일정 등록 | 기간/시간/유형(대내·대외)/부서/담당자/장소/참석자/내용 등 입력 |
| 🤖 AI 자연어 자동 입력 | 메모/메시지를 그대로 붙여넣으면 AI가 항목별로 자동 분류·입력 |
| 📋 리스트 / 캘린더 뷰 | 등록된 일정을 리스트 또는 월별 캘린더로 확인 |
| 🔍 검색 및 필터 | 부서·담당자·제목·장소·내용·유형별 필터링 |
| 📆 iCal 연동 | 구글/아웃룩 캘린더의 `.ics` 파일을 가져와 일괄 병합 |
| 📄 보고서 자동 생성 | 조회 조건(주간/월간/기간별)에 맞춰 미리보기 후 HWPX 파일로 다운로드 |
| ☁️ 구글 시트 연동(선택) | 로컬 저장소 또는 구글 스프레드시트를 실시간 DB로 사용 |

## 3. AI 개입 포인트 (How AI helps)

가장 핵심적인 자동화 지점은 **"비정형 텍스트 → 구조화된 일정 데이터" 변환**입니다.

**Before (입력 예시)**
```
기획조정실 홍길동 주무관(02-123-4567)이 6월 18일 오전 10시
정부세종청사 회의실에서 지자체 합동 점검 회의를 개최할 예정입니다.
```

**After (AI 자동 매핑 결과)**

| 필드 | 값 |
| --- | --- |
| 시작일 | 2026-06-18 |
| 시간 | 10:00 |
| 부서 | 기획조정실 |
| 담당자 | 홍길동 |
| 전화번호 | 02-123-4567 |
| 제목 | 지자체 합동 점검 회의 |
| 장소 | 정부세종청사 회의실 |
| 유형 | 대외/내부 자동 추정 |

- **Gemini API 사용 시**: 문맥을 이해해 항목을 정밀하게 추출
- **API 키 미입력 시**: 자체 휴리스틱(규칙 기반) 파서가 핵심 패턴(날짜, 시간, 전화번호, 부서명 등)을 추출하여 동작 → API 키 없이도 기본 동작 보장

> AI는 "데이터 입력을 도와주는 보조 도구"로만 사용되며, 최종 등록 전 사용자가 화면에서 항목을 검토·수정할 수 있습니다.

## 4. 작업 흐름 (Workflow)

```
[1] 일정 입력
     ├─ 직접 입력 (폼)
     ├─ AI 자연어 붙여넣기
     └─ iCal(.ics) 일괄 가져오기
        │
        ▼
[2] 데이터 저장
     ├─ 브라우저 로컬 저장소 (기본)
     └─ 구글 스프레드시트 (선택, 실시간 동기화)
        │
        ▼
[3] 조회 및 필터
     - 리스트 / 캘린더 뷰
     - 부서·담당자·기간·유형별 검색
        │
        ▼
[4] 보고서 생성
     - 조회 타입 선택 (주간 / 월간 / 기간별)
     - 미리보기로 내용 확인
     - HWPX 템플릿에 맞춰 파일 다운로드
```

## 5. 기술 스택 / 아키텍처

- **프론트엔드**: 순수 HTML + JavaScript (빌드 도구 불필요)
- **스타일**: Tailwind CSS (CDN)
- **AI**: Google Gemini API (클라이언트에서 직접 호출, 사용자 본인 키 사용)
- **데이터 저장**: 브라우저 LocalStorage (기본) 또는 Google Sheets + Apps Script (선택)
- **보고서 생성**: HWPX(zip+XML) 템플릿을 JSZip으로 직접 조작하여 생성

## 6. 실행 방법 (Quick Start)

### 설치
1. 이 저장소를 클론하거나 다운로드합니다.
2. `config.example.js` 파일을 복사하여 같은 폴더에 `config.js`로 저장합니다.
3. (선택) `config.js`의 `GOOGLE_WEB_APP_URL`에 본인의 구글 앱스 스크립트 웹 앱 URL을 입력합니다.

### 실행
별도의 빌드/서버 설치 없이 정적 HTML로 동작합니다.

- `index.html`을 더블클릭하여 브라우저에서 바로 엽니다.
- 또는 정적 서버로 실행:
  ```
  npx serve .
  ```

### 환경설정 (config.js)

| 변수명 | 설명 | 필수 여부 |
| --- | --- | --- |
| `GOOGLE_WEB_APP_URL` | 구글 스프레드시트 연동용 Apps Script 웹 앱 URL | 선택 (비워두면 브라우저 로컬 저장소 모드로 동작) |

> `config.js`는 `.gitignore`에 등록되어 GitHub에 올라가지 않습니다. 예시는 `config.example.js` 참고.
> Gemini API Key는 코드에 저장하지 않고, 화면 내 설정 패널에서 직접 입력 시 브라우저 로컬 저장소에만 저장됩니다.

### 구글 스프레드시트 연동
상위 폴더의 `구글시트설정.md` 문서를 참고하여 구글 앱스 스크립트를 배포하고, 발급받은 URL을 `config.js`에 입력하세요.

## 7. 한계 (Limitations)

- API 키 미입력 시 휴리스틱 파서는 정형화되지 않은 문장에서 정확도가 떨어질 수 있음
- 구글 시트 연동은 Apps Script 웹앱 배포에 의존하며, 응답 속도가 다소 느릴 수 있음
- HWPX 보고서는 특정 템플릿 구조를 전제로 하여, 템플릿 양식이 크게 다르면 매핑이 어긋날 수 있음
- 다중 사용자 동시 편집/권한 관리 기능은 없음 (개인/소규모 팀용)
